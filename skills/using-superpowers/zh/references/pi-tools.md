# Pi 工具映射

技能通过操作来实现（“派遣子代理”、“创建待办事项”、“读取文件”）。在 Pi 中，这些操作对应于以下工具。

| 操作技能请求 | Pi 对应功能 |
| --- | --- |
| 派遣子代理（`Subagent (general-purpose):` 模板） | 如有可用，使用已安装的子代理工具（例如来自 `pi-subagents` 的 `subagent`） |
| 任务跟踪（“创建待办事项”、“标记为已完成”） | 若有已安装的待办事项/任务工具则使用，否则在计划或 `TODO.md` 中跟踪任务 |

## 子代理

Pi 核心未随附标准子代理工具。`pi-subagents` 软件包是一个强大的可选配套组件，它提供了一个名为 `subagent` 的工具，支持单代理、链式、并行、异步、分叉上下文以及恢复/状态等工作流。 如果没有子代理工具，请勿伪造 `Task` 调用；应在当前会话中顺序执行，或说明该可选子代理功能未安装。

## 任务列表

Pi 核心未随附标准任务列表工具。如果安装了待办事项/任务扩展，请使用其文档中说明的工具。 否则，请使用 Superpowers 计划文件、Markdown 格式的检查清单，或本地仓库中的 `TODO.md` 进行任务跟踪。较早版本的 Superpowers 文档可能提及 `TodoWrite`；请将其视为上述任务跟踪操作。
