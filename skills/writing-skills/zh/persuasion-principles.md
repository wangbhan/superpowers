# 技能设计中的说服原则

## 概述

大型语言模型（LLMs）与人类一样，会遵循相同的说服原则。理解这一心理机制有助于您设计出更有效的技能——并非为了操纵用户，而是为了确保即使在压力下，关键操作也能得到执行。

**研究基础：** Meincke 等（2025）通过 N=28,000 次 AI 对话测试了 7 项说服原则。说服技巧使遵从率翻了一番多（33% → 72%，p < .001）。

## 七大原则

### 1. 权威
**定义：** 对专业知识、资质或官方来源的顺从。

**在技能中的应用：**
- 命令式语言：“你必须”、“绝不”、“必须”
- 不可协商的表述：“没有例外”
- 消除决策疲劳和合理化心理

**何时使用：**
- 纪律执行类技能（TDD、验证要求）
- 安全关键型实践
- 既定的最佳实践

**示例：**
```markdown
✅ Write code before test? Delete it. Start over. No exceptions.
❌ Consider writing tests first when feasible.
```

### 2. 承诺
**定义：** 与先前的行动、陈述或公开声明保持一致。

**在技能中的应用方式：**
- 要求公告：“宣布技能的使用”
- 强制明确选择：“选择 A、B 或 C”
- 使用跟踪机制：待办事项清单用于核对

**何时使用：**
- 确保技能得到切实执行
- 多步骤流程
- 问责机制

**示例：**
```markdown
✅ When you find a skill, you MUST announce: "I'm using [Skill Name]"
❌ Consider letting your partner know which skill you're using.
```

### 3. 稀缺性
**定义：** 由时间限制或资源有限所产生的紧迫感。

**在技能中的应用：**
- 限时要求：“继续之前”
- 顺序依赖关系：“X完成后立即”
- 防止拖延

**适用场景：**
- 需要立即验证的情况
- 对时间敏感的工作流程
- 防止“我稍后再做”

**示例：**
```markdown
✅ After completing a task, IMMEDIATELY request code review before proceeding.
❌ You can review code when convenient.
```

### 4. 社会认同
**定义：** 遵循他人的行为或被视为正常的行为。

**在技能中的应用原理：**
- 普遍模式：“每次”、“总是”
- 失败模式：“没有Y的X = 失败”
- 确立规范

**适用场景：**
- 记录普遍做法
- 警示常见失败
- 强化标准

**示例：**
```markdown
✅ Checklists without todo tracking = steps get skipped. Every time.
❌ Some people find a todo list helpful for checklists.
```

### 5. 团结
**定义：** 共同的身份认同、“我们”意识、内群体归属感。

**在技能中的应用：**
- 协作性语言：“我们的代码库”、“我们是同事”
- 共同目标：“我们都追求质量”

**适用场景：**
- 协作型工作流程
- 建立团队文化
- 非等级制的实践

**示例：**
```markdown
✅ We're colleagues working together. I need your honest technical judgment.
❌ You should probably tell me if I'm wrong.
```

### 6. 互惠
**定义：** 回报所获利益的义务。

**在技能中的应用：**
- 应谨慎使用——可能给人以操纵之感
- 在技能中极少需要

**应避免的情况：**
- 几乎所有情况（其他原则更有效）

### 7. 好感
**定义：** 倾向于与自己喜欢的人合作。

**运作机制：**
- **切勿用于强制服从**
- 与诚实反馈文化相冲突
- 会滋生阿谀奉承

**何时应避免：**
- 执行纪律时应始终避免

## 按技能类型划分的原则组合

| 技能类型 | 适用 | 避免 |
|------------|-----|-------|
| 纪律执行 | 权威 + 承诺 + 社会证明 | 好感、互惠 |
| 指导/技巧 | 适度权威 + 团结 | 强力权威 |
| 协作 | 团结 + 承诺 | 权威、好感 |
| 参考 | 仅清晰度 | 所有说服手段 |

## 为何有效：心理学原理

**明确的规则可减少合理化：**
- “你必须”消除了决策疲劳
- 绝对化的表述消除了“这算例外吗？”的疑问
- 明确的反合理化措施堵住了具体的漏洞

**实施意向能催生自动行为：**
- 明确的触发条件 + 必做动作 = 自动执行
- “当X时，做Y”比“通常做Y”更有效
- 减轻了遵守指令时的认知负荷

**大型语言模型（LLMs）具有超人类特性：**
- 基于包含这些模式的人类文本进行训练
- 训练数据中，权威性语言先于合规行为出现
- 承诺序列（陈述 → 行动）被频繁建模
- 社会证明模式（“大家都做X”）确立了规范

## 合乎伦理的使用

**正当用途：**
- 确保关键实践得到遵循
- 创建有效的文档
- 预防可预见的失败

**不恰当：**
- 为个人利益而操纵
- 制造虚假的紧迫感
- 基于内疚感的服从

**检验标准：**如果用户完全理解这一技巧，它是否真的符合用户的真实利益？

## 研究参考文献

**Cialdini, R. B. (2021).** *《影响力：说服的心理学（全新扩充版）》*. Harper Business.
- 说服的七大原则
- 影响力研究的实证基础

**Meincke, L., Shapiro, D., Duckworth, A. L., Mollick, E., Mollick, L., & Cialdini, R. (2025).** 《叫我混蛋：说服人工智能服从令人反感的请求》。宾夕法尼亚大学。
- 通过 N=28,000 次大型语言模型（LLM）对话测试了 7 大原则
- 运用说服技巧后，服从率从 33% 提升至 72%
- 权威、承诺和稀缺性最为有效
- 验证了LLM行为的“类人”模型

## 快速参考

设计技能时，请自问：

1. **属于哪种类型？**（纪律型 vs. 指导型 vs. 参考型）
2. **我试图改变什么行为？**
3. **哪些原则适用？**（通常纪律类情况适用权威 + 承诺）
4. **是否结合了太多原则？**（不要同时使用全部七项）
5. **这是否符合伦理？**（是否符合用户的真实利益？）
